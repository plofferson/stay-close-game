# Stay Close

A browser-based arcade game inspired by Battlefield — where your friends run away and then die. In this auto-runner you play as the friend who must **stay close** to Plofferson (the Anchor). Tap Jump to clear obstacles; if you get stuck on one, the world keeps moving and you get left behind — game over.

## Tech

- Vanilla HTML, CSS, and JavaScript (no frameworks)
- Canvas API for rendering
- Single-page, fully offline in the browser

## How to run

Open `index.html` in a modern browser (Chrome, Firefox, Edge).

## Features

- **Main menu** — Start Game, Choose Player, How to Play
- **Choose Player** — Pick from several characters (saved for the session)
- **Level 1** — Survive 60 seconds; jump over cars, house, and trenches; get stuck on an obstacle and you fall behind and die
- **Game Over / Win** — Themed messages, Retry, Next Level (placeholder), Main Menu

## Controls

- **Space / Up / W** or **JUMP button (mobile)** — Jump to clear obstacles
